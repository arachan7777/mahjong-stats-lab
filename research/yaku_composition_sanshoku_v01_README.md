## 定義
和了役構成比＝対象役を含む本人の和了回数÷本人の全和了回数×100。

- ロンとツモ、門前と鳴きを含める。
- 1回の和了で対象役が含まれたら1件。複合していても同じ役を二重計上しない。
- 異なる役は同じ和了からそれぞれ集計できるため、全役の構成比の合計が100%を超えても正常。
- ドラ／赤ドラ／裏ドラは通常の和了役とは区別する。
- 分母は成立した全和了イベント。試合数・参加局数・リーチ数ではない。
- 0件（分母0）の期間は割合NULL、該当期間の出力行が存在しなければ和了実績なし。
- 集計区分：通算・シーズン・ステージ・シーズン×ステージ、全選手を対象に最低和了回数の足切りなし。ランキングには分子・分母を併記する。
- 門前／鳴き、和了役に対する1翻／2翻／その他翻の内訳も出す。
