## 収録SQL
1. `sql/commentator_player_compat_v01.sql`：選手56名の対象実況時・その他実況時の試合数、累計pt、1試合平均pt、トップ率、ラス率、平均着順、相性差。双方20試合以上の順位適格フラグあり。
2. `sql/commentator_team_compat_v01.sql`：チーム10組の通算およびレギュラー成績。上記に加え、同卓する相手3チームの平均ポイントとの差と、持ち点25,000点からの増減も計算する。選手移籍は `game_player_result.team_id` を使用して、その試合時点の所属に反映する。
3. `sql/broadcast_commentary_master_20261120_v01.sql`：全2,068試合に実況者氏名を対応させるSQLite TEMPテーブルを作る準備SQL（独立したバックアップではなく正式卓外データの集計用写し）。

## 計算方法
- 1試合ポイント：`league_points + penalty_league_points`（反則減点を反映）。
- 実況相性差：対象実況時の1試合平均pt − その他実況時の1試合平均pt。
- トップ率：1着数 ÷ 対象条件の出場試合数。
- チームの「対戦相手3組との得失点差」：当該チームの1試合pt − 同卓3チームの1試合平均pt。これは「日吉実況時／それ以外」の各条件で集約できる。
- 累計ptの単純比較は出場試合数の差を含むため、相性順位には平均ptの差を採用する。
- 標準表示順位は、日吉実況時・その他実況時とも20試合以上の条件。全選手・全チームの行はフィルターで削除しない。
- 対象実況者の変更は各SQLの`target` CTEにある氏名のみ。既存の原典を変更せず他実況者も分析できる。

## 実行方法（SQLite）
1. 正本DBを読み取り専用で開く。
2. 実行セッションのTEMP領域へ `sql/broadcast_commentary_master_20261120_v01.sql` を読み込む。
3. 同一セッションで選手別・チーム別の各SQLを実行する。
4. 原典DBの既存表への書き込みは不要。
