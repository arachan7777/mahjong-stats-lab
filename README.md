# 麻雀スタッツ研究所 — データ更新基盤

Mリーグの公開牌譜データベースを取得し、独立した実行環境で検証するためのリポジトリ。

## 現在の実装範囲（第1段階）

- konoui氏の `m-league-game-db` の最新リリースを取得
- `database.zip` からSQLiteデータベースを一時展開
- SQLiteの `PRAGMA quick_check` で整合性を検査
- 試合数・局数・イベント数・最終試合日を取得
- 2026-09-22時点の既存データより件数・最終日が減少していないか検査
- 集計結果、リリース番号、取得ファイルのSHA-256を小さなレポートとして保存

**現段階では独自指標を再計算していない。** 既存の独自SQLには、最新版で変更されたテーブル・列への対応が必要。

## 実行方法（スマートフォンのブラウザにも対応）

リポジトリの「Actions（自動処理）」→「Mリーグ最新版DBの検証」→「Run workflow（処理を開始）」で手動実行できる。

実行結果は該当の実行履歴内の「Artifacts（成果物）」から `ml-db-validation-report` を確認できる。中身は `summary.md` と `summary.json`。

初期設定では手動実行のみ。定期実行は行わない。

## データの扱い

- 検証対象は公開元のデータであり、このリポジトリには生の牌譜DBを登録しない。
- 約300MBのZIPや展開後のSQLiteファイルはGitHub Actionsの一時環境だけで利用し、成果物として保存しない。
- 検証レポートのみ短期間（7日間）保存する。
- Googleドライブ上の `【麻雀スタッツ研究所】/database.sqlite3` には接続・上書きしない。
- このリポジトリは現時点で公開設定。秘密情報や未公開データは配置しない。

## 既存DBとの比較基準

2026-11-12の既存DB検証記録を基準として、試合1,932件、局23,550件、イベント2,573,037件、最終日2026-09-22を照合対象とする。これは**件数の下限チェック**であり、同一試合IDの対応や独自指標の同値性を保証するものではない。
