# 第22指標群「配牌格差社会」 v0.1

親・子とも第一ツモ前の配牌13枚を対象に、選手別・リーグ全体について通算およびシーズン別に比較する。本場ごとに別局とし、分母は各集計対象の参加人局数。

1. 配牌シャンテン数の平均と分布。通常形・七対子・国士無双の最小値を使う。
2. 配牌に含まれる表ドラの平均枚数。最初の表ドラ表示牌が指す牌を数える。
3. 配牌に含まれる赤ドラの平均枚数。赤五萬・赤五筒・赤五索を各1枚と数える。
4. 配牌ドラ3以上率＝表ドラと赤ドラが合計3枚分以上の人局数÷参加人局数×100。表ドラに該当する赤5は表1＋赤1の計2枚分。例えば表2＋赤1で該当する。

4項目を並べて比較する。初手有効牌ツモ率は別指標。第16指標「やってんな配牌率」は配牌シャンテン数が0または1の割合。

固定版 20261120-2341-04338cbb、100,952人局。平均シャンテン数3.5508、表ドラ平均0.3847枚分、赤ドラ平均0.2892枚、配牌ドラ3以上2,255人局（2.2337%）。
